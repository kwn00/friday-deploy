# v0.0.2 — 필드 아이템, 부활, 듀얼 모니터

## 달라진 점

- **필드 아이템**: 적을 잡지 않아도 맵 어딘가에 아이템이 가끔 놓입니다.
  평균 110초에 하나, 살아 있는 플레이어에게서 500~800px 떨어진 곳(화면 밖)에 놓이고, 동시에 최대 3개, 90초 동안 줍지 않으면 사라집니다.
  - 🍕 **야근 피자** (65%): 체력 20% 회복. 체력이 가득이면 줍지 않고 남겨 둡니다
  - ✅ **LGTM** (34%): 즉시 1레벨 업. 모으던 경험치는 그대로 두고 강화 선택지가 바로 뜹니다
  - 💾 **백업** (1%): 가지고 있으면 쓰러질 순간에 그 자리에서 체력 절반으로 되살아납니다. 2초 동안 피해를 받지 않고 주변의 적이 밀려납니다. 하나만 가질 수 있습니다
- **미니맵**: 필드 아이템을 거리와 상관없이 표시합니다. 범위 밖이면 가장자리에 붙어 방향을 알려주고, 새로 놓인 것은 4초 동안 테두리가 퍼집니다
  (피자는 초록 십자, LGTM 은 노란 마름모, 백업은 하늘색 네모).
- **알림과 표시**: 새 아이템이 놓였을 때, 백업을 주웠을 때, 백업으로 되살아났을 때 짧은 알림이 뜹니다. 가지고 있는 백업은 강화 목록 옆에 표시됩니다.
  곧 사라질 아이템과 방금 되살아난 캐릭터는 깜빡입니다 (기기의 "동작 줄이기" 설정에서는 깜빡이지 않고 흐리게만).
- **새 강화 🖥️ 듀얼 모니터**: 한 단계에 공격 범위 +12% (최대 5단계). 더 멀리 있는 적을 겨누고, 탄이 더 멀리 날아가고, 러버덕이 도는 반경이 넓어집니다.
- **리더보드 시즌 2**: 게임이 달라져서 새 순위표로 시작합니다. 이전 시즌의 기록은 DB 에 남아 있지만 화면에는 보이지 않습니다.

## 난이도에 미치는 영향 (봇으로 측정)

같은 시드에서 이전 버전과 비교했습니다 (혼자 하기, 판당 약 5분, 변형마다 110~170판).

- 아이템을 찾아다니는 봇의 생존 시간: 중앙값 약 +5% (95% 구간 -9% ~ +17%). 이전 버전과 구분되지 않는 수준입니다.
  처음에 잡았던 75초 간격에서는 +27%(상위 25% 는 +47%)여서 110초로 늦췄습니다.
- 아이템을 무시하는 봇: 차이 없음.
- 백업은 5분쯤 되는 판의 2~6% 에서 등장했습니다.
- 듀얼 모니터는 다른 패시브보다 강하지 않습니다 (이 봇에게는 효과가 거의 없었습니다. 정규표현식·AI 에이전트 위주의 조합에서는 재지 않았습니다).

## 내부 변경

- 아이템이 언제·어디에·무엇이 놓일지는 서버의 비밀 난수(운영체제 CSPRNG)로만 정합니다. 보이는 난수를 쓰지 않아 적 스폰의 흐름에 영향이 없습니다.
- 줍기, 레벨업, 부활, 무적 시간은 모두 서버가 판정합니다. 클라이언트는 지금처럼 이동 입력만 보냅니다.
- 스냅샷에 필드 아이템(거리와 상관없이 전부), 내 백업 수, 플레이어별 "무적 중" 표시와 공격 범위 단계를 싣습니다.
  이진 규격 3, 통신 규격(프로토콜) 5. 전송량은 아이템 3개가 다 있을 때 초당 약 600바이트 늘어납니다.
- 러버덕은 서버 판정과 화면이 같은 반경을 쓰도록, 플레이어의 범위 단계로 같은 식을 계산합니다.
- 문서: README, docs/SECURITY.md (아이템 예측·조작, 부활 조작 항목 추가).

- 확인하지 못한 것: 운영 사이트와 실제 휴대폰, 2~4명이 함께 하는 판에서의 난이도.
