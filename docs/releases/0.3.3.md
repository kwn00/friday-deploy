# v0.3.3

## 달라진 점

- **화면 밖 아이템이 화면 가장자리에 보입니다.** 화면 밖에 있는 필드 아이템(🍕 야근 피자 · ✅ LGTM · 💾 백업)과 보물상자를, 그쪽 화면 가장자리에 아이템 그림을 담은 네모와 화살표로 보여 줍니다. 미니맵을 꺼 둬도 보입니다.
  - 화면 가운데에서 아이템 쪽으로 가다가 화면 끝이나 HUD(체력바, 시간·메뉴 버튼, 미니맵, 장비, 알림)에 닿기 직전에 놓입니다. HUD 에 가려진 아이템도 표시합니다.
  - 같은 쪽에 몰려 있으면 겹치지 않게 조금씩 비켜 놓고, 화살표는 언제나 아이템을 가리킵니다.
  - 보물상자는 가까운 3개까지 표시합니다 (미니맵에는 모두 보입니다).
  - 새로 놓인 것은 4초 동안 테두리가 퍼지고, 곧 사라질 것은 깜빡입니다. 기기의 "동작 줄이기" 설정이 켜져 있으면 테두리는 고정되고, 깜빡이는 대신 흐리게 보입니다.
  - 아이템이 화면 밖에 놓였을 때의 알림은 "화면 끝 화살표를 따라가요"라고 알려 줍니다 (예전: "미니맵을 보세요").
- **🧹 git clean 은 보물상자를 지우지 않습니다.** git clean 은 저절로 터지므로, 보스를 잡고 상자로 걸어가는 사이에 터지면 상자가 사라졌습니다. 이제 상자는 어느 쪽이 나와도 남습니다.
- **🧹 git clean 이 지우는 쪽이 나오면 화면 안의 필드 아이템(피자·LGTM·백업)도 지웁니다.** 예전에는 필드 아이템은 지우지 않았습니다. 지우는 범위는 경험치·적을 지우는 범위와 같고(캐릭터에서 304px, 화면의 가장 먼 모서리 바로 바깥까지), 쓸 때마다 한 번 굴려 경험치·회복 아이템·필드 아이템을 함께 남기거나 함께 지웁니다. 남길 확률은 그대로입니다 (1~2단계 10%, 3~4단계 25%, 5~6단계 45%, 7~8단계 65%, 배포 기도로 커짐). ♻️ rm -rf node_modules 는 예전처럼 아무것도 지우지 않습니다.

## 고친 것

- git clean 에 지워진 경험치·회복 아이템이 캐릭터 가까이에서 사라지면 주운 것처럼 반짝이고 소리가 났습니다. 이제 지워진 것은 조용히 사라집니다.

## 내부 변경

- **git clean** (`packages/shared/src/combat.ts`): 지우는 쪽의 필드 아이템 조건을 `it.kind === 'chest' || !inView(...)` 로 바꿨습니다 (서버의 시뮬레이션이 판정합니다). 방금 떨어진 상자를 남기려고 쓰던 `FieldItem.born` 은 쓸 데가 없어 뺐습니다. 무기 설명: "경험치·아이템도 자주 지워지지만 보물상자는 남는다".
- **지워진 것과 주운 것 구분** (`apps/client/src/sound-cues.ts`, `render.ts`): 화면은 직전 장면과 비교해 사라진 것을 "주웠다"고 봅니다. 이제 git clean 의 지우기 영역(`wipe`, aux 0) 안에서 사라진 경험치·회복 아이템·필드 아이템은 주운 것으로 보지 않습니다. 영역은 서버가 한 번만 보내므로, 받는 대로 기억해 둔 영역 중 직전에 보인 틱 뒤부터 지금 틱까지 실려 온 것으로 찾습니다(`wipesBetween`). 그 스냅샷이 화면에 나오지 않고 지나가도(긴 프레임, 멈춘 동안 같은 틱의 스냅샷이 덮어씀) 놓치지 않습니다. 보물상자는 지워지지 않으므로 이 검사를 하지 않습니다.
- **화면 가장자리 표시** (`apps/client/src/edge.ts`, `render.ts`, `main.ts`): 자리 계산은 DOM 을 쓰지 않는 순수 함수(`edgeSpot`, `placeEdge`, `pickEdgeTargets`, `hiddenAt`)로 나누고 단위 테스트를 붙였습니다. HUD 요소의 자리는 `main.ts` 가 0.25초에 한 번(화면 크기가 바뀌면 바로) 재서 넘깁니다 (글자가 바뀔 때마다 재면 레이아웃 계산이 잦아지므로).
- 서버가 보내는 값은 그대로입니다: 필드 아이템은 거리와 상관없이, 보물상자는 미니맵 범위의 두 배 안의 것만 보냅니다. 통신 규격 버전, 전송량, 서버 계산량은 그대로입니다.
- 리더보드 시즌, 기록 형식은 그대로입니다. 지운 기록은 없습니다.
- 문서: README (화면 가장자리 표시, 필드 아이템과 git clean, 보물상자), docs/SECURITY.md (필드 아이템 위치를 모두에게 보내는 이유에 가장자리 표시 추가).

## 확인한 것

- 타입 검사, 클라이언트 빌드, DB 없이 돌린 단위 테스트 통과. 새 테스트: git clean 의 지우는 쪽·남기는 쪽에서 화면 안팎의 필드 아이템과 땅에 있던 보물상자, rm -rf node_modules, 지워진 것의 소리(건너뛴 스냅샷 포함)와 지우기 영역 안에서 연 상자의 소리, 가장자리 표시의 자리 계산(화면 끝, HUD, 노치 여백, 최소 거리, 몰린 표시 비켜 놓기, 보물상자 3개). git clean 테스트는 고치기 전 코드로 되돌리면 실패하는 것을 확인했습니다.
- 실제 서버를 띄우고 실제 브라우저(Chromium)로 혼자 하기를 했습니다. 확인용으로 플레이어 둘레에 아이템을 놓는 임시 코드를 넣었습니다 (커밋하지 않음).
  - 320×568 · 568×320 · 390×844 · 844×390 · 768×1024 · 1280×800 · 1920×1080 에서 표시가 화면 끝과 HUD·알림을 피하고, 겹치지 않고, 아이템을 가리킵니다. 미니맵을 끄면 그 자리까지 씁니다. 동작 줄이기 설정에서는 테두리가 고정되고 곧 사라질 것은 흐리게 보입니다. 콘솔 오류는 없습니다.
  - 화면 안에 필드 아이템과 보물상자를 둔 채 git clean 을 받게 해 지우는 쪽이 나온 판에서, LGTM·백업은 지워지고 보물상자 둘은 남았습니다.
