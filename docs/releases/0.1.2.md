# v0.1.2

무기, 강화, 난이도를 뱀파이어 서바이버즈 위키의 수치와 규칙에 맞췄습니다 (진화는 없습니다). 위키 페이지의 원문(무기 23, 패시브 15, 적, 레벨업, 경험치, 보물상자, 사신, 저주 등 70여 쪽)을 받아 표로 옮기고, 옮긴 숫자를 원문과 다시 대조했습니다. 스테이지(몇 분에 어떤 적이 몇 마리)는 뱀서의 스테이지를 그대로 옮기지 않고 같은 규칙으로 새로 짰습니다.

## 달라진 점

### 무기
- 23종 모두 피해·쿨다운·개수·지속·관통·최대 단계·단계별 증가분을 위키 값으로 바꿨습니다. 크기와 속도는 우리 화면 단위라 기본값은 그대로 두고, 단계마다 커지는 비율만 옮겼습니다.
  - 예: 🖨️ console.log() 1단계 피해 10 · 쿨다운 1.2초(8단계 30 · 1.0초 · 4발), 🔣 정규표현식 6.5(8단계 16.5 · 6발), 🧱 벽돌책 20(8단계 80), ⚡ 핫 리로드 15(8단계 65 · 6번), 🧹 git clean 쿨다운 90초(8단계 60초).
  - 최대 단계: 🧊 코드 프리즈 7, 🔐 2단계 인증 7, 🧵 멀티스레드 6, 나머지 8.
- 동작도 위키에 맞췄습니다.
  - 🖨️ console.log(): 여러 발을 가까운 적부터 차례로 겨눕니다 (부채꼴로 퍼지던 것을 고쳤습니다).
  - 🦆 러버덕: (쿨다운 + 지속)마다 켜지고, 같은 버그는 오리마다 1.7초에 한 번만 맞힙니다.
  - 🐤 카나리아 · 🦉 야근 부엉이: 4초 동안 1초마다 폭탄을 한 묶음씩 퍼붓고 쉽니다. 처음부터 4개씩.
  - 🔐 2단계 인증: 방패를 만듭니다. 맞을 때 방패가 대신 막고 잠깐 무적이 됩니다 (4·7단계에 방패 하나씩 더).
  - 🧹 git clean: 화면 안의 버그를 사신만 빼고 모두 지웁니다. 쓸 때마다 한 번 굴려서, 대개는 경험치·회복 아이템·보물상자까지 지우고, 가끔(단계가 오를수록 자주)은 경험치를 주고 아이템을 남깁니다.
  - 🧊 코드 프리즈: 빙결 저항이 1보다 큰 보스는 얼지 않습니다.
  - 👣 커밋 히스토리: 움직이는 동안 커밋을 남기고, 멈추면 바라보는 쪽으로 한꺼번에 날립니다 (오래 남아 있던 것일수록 셉니다).
  - 🌪️ 스프린트: 바라보는 쪽 옆으로 여러 번 벱니다. 쉬지 않고 걸을수록 피해가 늘어납니다. 가끔 치명타(2배).
  - 🧵 멀티스레드(전 로직 폭탄): 터지지 않고, 무작위 버그 하나에게 여러 발을 보냅니다.
  - ↩️ 롤백: 되돌아온 뒤 던진 자리를 지나 계속 날아갑니다. 🤖 AI 에이전트: 무작위 버그 하나에게 여러 발을 부채꼴로 (엉뚱한 곳을 쏘던 것은 없앴습니다).
  - 🔥 방화벽: 밀어내지 않는 대신 맞을수록 잘 밀리고 잘 얼게 만듭니다.
  - 무기마다 맞힌 버그를 잠깐 밀어내는 넉백이 생겼습니다 (무기마다 세기가 다릅니다).
  - 무기를 얻거나 올리면 바로 한 번 씁니다.

### 패시브
- 🌙 다크 모드: 최대 체력이 단계마다 1.2배씩 곱해집니다 (5단계 2.49배). 고를 때 회복하지는 않습니다.
- 📦 npm install: 끌어당기는 범위가 1.5배, 1.33배, 1.25배, 1.2배, 1.33배 (5단계 3.98배).
- 🙏 배포 기도: 운 +10%. 운이 좋으면 선택지가 4개 나오고(5단계 약 33%), 보물상자가 좋아집니다.
- 🧪 테스트 커버리지: 한 대 맞을 때마다 피해 -1 (최소 1).
- 🧘 워라밸: 회복 아이템이 더 잘 듣습니다 (5단계 +100%).
- ☠️ 운영 서버 직접 수정(저주): 버그의 체력은 바로, 속도·수·빈도는 다음 분부터 늘어납니다. 경험치는 늘리지 않습니다.
- 📸 스냅샷: 스냅샷으로 받은 부활을 다 쓰면 칸에서 빠져 다시 얻을 수 있습니다.

### 레벨업
- 필요한 경험치가 위키 공식을 따릅니다 (1→2 는 5, 그 뒤 10씩 늘고, 20·40 레벨에서 크게 늘어나는 대신 그 레벨에 있는 동안 경험치 +100%).
- 선택지는 강화마다 정해진 무게(드문 것은 덜 나옴)로 뽑고, 가진 것을 먼저 넣을 기회가 두 번 있습니다.
- 모두 최대 단계면 체력 30을 채웁니다.
- 경험치 조각이 크기에 따라 파랑(2 이하) · 초록(9 이하) · 빨강으로 보입니다. 땅에 400개가 넘으면 새 경험치는 빨간 조각 하나에 모입니다 (지워지던 것을 고쳤습니다).

### 맞는 방식
- 붙어 있는 버그마다 1초에 몇씩 깎이던 것을, 한 대씩 맞고 0.24초 동안 무적이 되도록 바꿨습니다. 여러 마리에 둘러싸여도 한 대씩입니다.
- 레벨업을 고른 뒤, 보물상자를 연 뒤에도 잠깐 무적입니다.
- 🍕 회복 아이템은 체력 30을 채웁니다 (전에는 최대 체력의 20%).

### 버그와 스테이지
- 새 버그 7종: 빨간 버그, Off-by-one, 오타(빠름), 머지 지옥, 기술 부채(아주 단단함), 깨지는 테스트(둘레를 에워쌈), 버그 떼(한 방향으로 가로지름). 수치는 뱀서의 같은 역할 적과 같습니다.
- 새 보스 4종: 왕버그, God Class, 모놀리스, 스파게티 코드 (레거시 코드도 보스로 남았습니다). 보스는 나올 때 가까운 사람의 레벨만큼 체력이 곱해지고, 멀어져도 화면 근처로 다시 옵니다.
- **보물상자**: 보스를 잡으면 떨어집니다. 직접 닿아야 열리고, 5개 → 3개 → 1개 순서로 굴려(운이 좋을수록 잘 나옴) 가진 무기·패시브를 그만큼 한 단계씩 올립니다.
- 1분마다 웨이브가 바뀝니다. 화면의 버그가 그 분의 최소 수보다 적으면 한꺼번에 채우고, 많으면 간격마다 종류별로 한 마리씩 더 나옵니다. 300 마리부터는 더 나오지 않습니다 (보스와 이벤트는 500 마리까지).
- **30분이 되면 월요일 아침이 옵니다**: 화면의 버그가 모두 사라지고, 한 대에 쓰러뜨리는 적이 1분마다 하나씩 옵니다.
- 함께 하기는 지금처럼 사람이 늘면 버그가 더 많이 나옵니다 (상한은 같습니다).
- 순위표는 바꾸지 않았습니다.
