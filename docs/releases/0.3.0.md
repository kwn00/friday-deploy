# v0.3.0

## 달라진 점

- **무기 진화.** 최대 단계인 무기와 짝이 맞는 패시브(단계는 상관없음)를 함께 가지고 보물상자를 열면, 그 무기가 진화합니다. 진화한 무기는 원래 무기의 칸을 쓰고 더 오르지 않습니다. 짝 패시브는 그대로 남습니다.

  | 무기 (최대 단계) | + 패시브 | → 진화 | 바뀌는 것 |
  | --- | --- | --- | --- |
  | 🖨️ console.log() | 🧪 테스트 커버리지 | 🐞 디버거 | 중단점을 쏩니다. 꿰뚫고 날아가, 맞은 버그가 잠깐(0.3초) 멈춥니다. 보스는 멈추지 않습니다 |
  | 🏓 핑퐁 | ⏳ keep-alive | 🔌 웹소켓 | 공이 끊이지 않고 튕기며 계속 맞힙니다 |
  | 💧 핫픽스 | ☠️ 운영 서버 직접 수정 | 🌋 금요일 배포 | 내 발밑과 버그들 자리에 불이 붙습니다 |
  | 🧹 git clean -fd | 📦 npm install | ♻️ rm -rf node_modules | 화면을 지워도 경험치·아이템이 언제나 남고, 화면의 경험치를 모두 끌어당깁니다 (끌려오는 동안 레벨업을 골라도 기다렸다가 마저 옵니다). 쿨다운 45초 |

- **합치기.** 두 무기가 모두 최대 단계이면 보물상자에서 하나로 합쳐지고, 무기 칸 하나가 빕니다.
  - 🐤 카나리아 + 🦉 야근 부엉이 → 🕐 **24시간 모니터링**: 두 마리가 쉬지 않고 함께 돌며 폭탄을 떨어뜨립니다.
  - 📡 브로드캐스트 + 📨 멀티캐스트 → 🌊 **패킷 플러딩**: 여덟 방향으로 패킷을 쏩니다.
- **짝 안내.** 레벨업 선택지 카드에 그 무기·패시브로 무엇이 되는지 나옵니다 (예: "✨ 진화: 최대 단계 + 🧪 테스트 커버리지 → 🐞 디버거").
  조건이 맞아 보물상자를 열면 진화할 무기는 칸이 노란 테두리로, 진화한 무기는 보라 테두리와 ★ 로 보입니다. 순위표에도 ★ 로 나옵니다.
- **진화 알림.** 보물상자 알림에 "✨ 디버거 진화!" 처럼 나오고, 짧은 축하 소리가 납니다.
- 진화한 무기와, 진화해서 없어진 재료 무기는 레벨업 선택지에 나오지 않습니다.

## 내부 변경

- **콘텐츠**: `content.ts` 의 `EVOLUTIONS` (진화 4 + 합치기 2), `readyEvolutions`·`evolvedAway`·`evolutionOf`. 진화한 무기 6종은 `WEAPON_IDS` 맨 뒤에 붙였습니다 (단계 1, 레벨업 무게 0).
- **판정은 서버**: 진화할지는 서버가 보물상자를 열 때 서버의 강화 단계로만 정합니다 (`sim.ts` `openChest`). 진화를 요청하는 메시지는 없습니다. 진화는 난수를 쓰지 않습니다.
- **경험치 끌어당기기**: rm -rf node_modules 가 끈 경험치는 주인이 레벨업을 고르는 동안 그 자리에서 기다립니다 (함께 하는 판은 고르는 동안에도 월드가 돌기 때문). 그동안 땅이 가득 차면 같은 주인을 기다리는 것 둘을 하나로 합쳐 자리를 만들어서, 동료가 잡은 적도 그 자리에 경험치를 떨어뜨립니다. 다른 경험치는 예전과 같습니다.
- **수치**: 진화한 무기는 우리 게임의 것입니다. 같은 조건(적 120마리, 60초)에서 재료 무기 최대 단계와 비교한 피해: 디버거 2.4배, 웹소켓 2.2배, 금요일 배포 3.0배, 24시간 모니터링 1.5배(+ 칸 하나), 패킷 플러딩 1.9배(+ 칸 하나).
- **통신**: 투사체 종류 `breakpoint`·`socket`, 바닥 영역 `fire` 를 뒤에 붙였습니다. 강화 단계 목록이 늘어서 통신 규격 버전 10 → 11, 이진 스냅샷 버전 7 → 8 (예전 화면은 새로 고치라는 안내를 받습니다).
- **통계 API**: 진화한 무기에 재료(`evolve: { from, with }`)를 싣습니다. 진화한 무기의 `chest` 는 진화한 횟수입니다. 0.3.0 의 통계는 버전별로 따로 쌓입니다 (`?version=0.3.0`).
- 리더보드 시즌은 그대로(시즌 0)입니다. 기록 형식도 그대로라 예전 기록은 그대로 보입니다.

## 확인한 것

- 단위 테스트 267개 통과 (PostgreSQL 테스트 포함). 새로 추가: 진화 목록의 규칙, 진화 조건(최대 단계·짝 패시브·한 번만), 보물상자에서의 진화(1개·5개짜리 상자, 둘이 함께, 합치기로 칸이 빔), 진화한 무기와 재료 무기가 선택지에 나오지 않음, 진화한 무기 6종의 동작(디버거는 보스를 멈추지 않음, 함께 하는 판의 rm -rf 끌어당기기와 주인이 나갈 때·땅이 가득할 때 포함), 이진 스냅샷 왕복, 통계 API 의 재료, 선택지 짝 안내와 상자 알림 문구.
- 진화가 없는 판은 예전과 똑같이 흘러가는 것을 확인했습니다 (예전 코드와 같은 시드로 여러 판을 돌려 결과가 같음).
- 보물상자를 찾아다니며 진화 재료를 먼저 고르는 봇으로 30분씩 12판: 9판에서 진화했고, 첫 진화는 가운데 13분쯤, 한 판에 1~5개였습니다.
- 서버 계산과 전송량: 진화한 무기는 재료 무기와 비슷합니다 (틱당 0.1ms 안쪽, 스냅샷 크기 차이 30바이트 안쪽).
- 실제 서버와 실제 브라우저(Chromium)로 320×568 · 568×320 · 390×844 · 844×390 · 1280×800 에서 선택지 짝 안내, 칸 표시, 보물상자 진화와 알림, 진화한 무기 6종이 그려지는 것을 확인했습니다.
