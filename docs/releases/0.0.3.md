# v0.0.3

## 달라진 점

- **끊긴 연결 다시 붙기**: 연결이 끊겨도 그 판이 끝나지 않습니다. 서버가 자리를 지켜 두고, 화면이 스스로 다시 연결해서 같은 캐릭터로 이어서 합니다.
  다른 앱에 다녀왔을 때, 와이파이와 데이터가 바뀌었을 때, 실수로 새로고침했을 때 모두 해당합니다.
  - **혼자 하기**: 끊긴 동안 게임이 멈춥니다 (일시정지와 같은 한도: 한 번에 최대 10분, 한 판에 합쳐서 30분). 돌아오면 메뉴가 떠 있고, 계속하기를 누르면 이어집니다.
  - **함께 하기**: 게임은 멈추지 않고, 끊긴 사람의 캐릭터는 그 자리에 서서 계속 맞습니다. 2분 안에 돌아오면 같은 캐릭터로 이어서 합니다.
    2분이 지나면 자리가 비워지고, 같은 방에 코드로 다시 들어갑니다 (진행 중인 판이면 그 판은 관전).
  - **대기실**: 대기실이 닫힐 때까지 자리를 지킵니다. 초대 링크를 보내러 다른 앱에 다녀와도 방이 남아 있습니다.
    방장의 연결이 끊겨 있는 동안에는 접속해 있는 사람이 시작할 수 있고, 시작하면 끊긴 사람은 빼고 시작합니다 (돌아오면 코드로 다시 들어옵니다).
- **연결이 죽은 것을 화면이 직접 알아챕니다**: 휴대폰은 연결이 죽어도 브라우저가 한참 동안 알려주지 않습니다. 이제 서버에서 4초 동안 아무것도 오지 않으면 화면이 알아채고 다시 연결합니다.
- **다시 연결하는 중 화면**: 금방 다시 붙으면 뜨지 않고, 오래 걸리면 이유를 알려줍니다. `그만두기`를 누르면 서버에 자리를 비우라고 알리고 타이틀로 나갑니다.
- **혼자 하기에서 서버가 멈춰 둔 경우**: 돌아오면 메뉴가 열려 있고, 왜 멈췄는지(화면을 떠나서인지, 연결이 잠깐 끊겨서인지) 알려줍니다.
- **동료의 연결 상태**: 연결이 끊겼거나 화면을 떠난 동료는 이름 옆에 💤 가 붙고, 대기실에는 "연결 끊김"으로 표시됩니다. 끊겼을 때와 돌아왔을 때 짧게 알려줍니다.
- **화면을 떠나면 캐릭터가 멈춥니다**: 함께 하기에서 다른 탭이나 앱으로 가면, 화면이 가려진 동안에는 입력을 보낼 수 없어 누르고 있던 방향으로 계속 달릴 수 있었습니다. 이제 떠나는 순간 멈춥니다.
- `나가기` · `그만두기`는 자리를 바로 비웁니다 (전과 같습니다).
- 자리가 없어져서 하던 방에 다시 들어가지 못하면, 방이 사라졌는지 가득 찼는지 구분해서 알려줍니다.

## 내부 변경

- **자리와 열쇠**: 자리마다 운영체제 CSPRNG 로 만든 192비트 열쇠를 `welcome` 에 실어 줍니다. 새 메시지 `resume` 에 이 열쇠를 내면 그 자리를 이어받습니다.
  열쇠는 어느 자리인지 가리킬 뿐입니다. 체력·위치 같은 상태는 서버에만 있고, 클라이언트가 실어 보내는 값은 없습니다.
- **끊어서 얻는 것이 없게**: 자리를 지키는 동안 캐릭터는 무적이 아니고, 페어 판은 멈추지 않습니다. 혼자 하는 판의 멈춤은 일시정지와 같은 예산을 쓰고 기록에도 일시정지 시간으로 남습니다.
  연결이 끊기는 순간 그 판은 누가 나간 것과 똑같이 막혀서, 끊긴 사람이 코드로 새로 들어와 새 캐릭터를 받을 수 없습니다.
- **서버가 끊은 연결은 자리를 지켜 주지 않습니다**: 규칙 위반이나 속도 제한으로 끊긴 연결은 닫히기를 기다리지 않고 자리를 바로 비웁니다. 새 메시지 `leave` 도 자리를 바로 비웁니다.
- **입력이 멈춘 연결**: 판이 진행되는 동안 4초 넘게 입력이 없으면 캐릭터를 세우고, 혼자 하는 판은 스스로 멈춥니다. 죽은 연결을 하트비트가 알아채기까지(15~30초) 캐릭터가 마지막 입력대로 달리지 않습니다.
- **주소당 한도**: 연결 없이 지켜 두는 자리는 주소당 6개까지, 연결 수와 합쳐서 셉니다. 넘치면 그 주소의 가장 오래된 자리부터 비웁니다 (연결을 끊어 두는 방법으로 방을 한도보다 많이 붙잡아 둘 수 없습니다).
- **놓친 결과 다시 전하기**: 판이 끝나는 순간 통신이 막혀 있던 사람은 돌아왔을 때 결과를 받습니다. 혼자 하는 판은 끝난 뒤 2분 동안, 열쇠가 맞는 사람에게만 줍니다.
- 이어받기 열쇠는 브라우저의 탭 저장소(sessionStorage)에 둡니다 (새로고침 뒤에도 이어지게). 나가거나 판이 끝나면 지웁니다.
- **통신이 막힌 동안에는 입력을 쌓아 보내지 않습니다**: 서버에서 1.5초 넘게 아무것도 오지 않으면 입력을 보내지 않고, 다시 오기 시작하면 최신 값만 보냅니다 (막혔다 풀릴 때 쌓인 입력이 한꺼번에 쏟아져 서버의 속도 제한에 걸리지 않게).
- **연결 감시**: 서버에서 오는 것이 끊기면 2초 간격으로 ping 을 보내 물어보고, 4초 동안 조용하면 죽은 연결로 봅니다. 페이지가 멈춰 있다 깨어난 경우(다른 앱에 다녀옴)에는 그동안의 침묵을 세지 않습니다.
- 통신 규격(프로토콜) 6. 스냅샷의 이진 규격은 그대로입니다. 리더보드 시즌도 그대로입니다 (난이도는 달라지지 않았습니다).
- **전송량** (브라우저에서 20초씩 잰 값): 플레이 중에는 늘지 않습니다 (ping 0개. 스냅샷이 오는 동안에는 보내지 않습니다). 대기실에서는 초당 약 22바이트(한 시간에 약 80KB), 혼자 하기 일시정지 중에는 초당 약 57바이트입니다. 플레이 중 스냅샷은 초당 약 2.2KB 입니다.
- 문서: README, docs/SECURITY.md (새 메시지 2종, 위협 9항목, 알려진 한계 갱신).

## 알아 둘 것

- 서버가 새로 시작되면(배포, 호스트의 재시작) 하던 판은 이어갈 수 없습니다. 방과 자리가 서버 메모리에 있기 때문입니다.
- 연결이 끊긴 채로 탭을 닫으면 나갔다고 알릴 방법이 없어서, 함께 하는 판에서는 캐릭터가 최대 2분 동안 서 있습니다.

- 실제 서버에 프로토콜을 손으로 짠 클라이언트로 재접속 검사 38건: 이어받기, 다른 연결이 이어받기(4009), 틀린 열쇠·한 글자 다른 열쇠·없는 방(같은 답), 토큰 재사용, 쫓겨난 뒤 이어받기, 끊긴 뒤 코드로 들어오기(관전), 체력이 채워지지 않음, 입력이 멈춘 연결, 주소당 한도, 끝난 판의 결과 전달. 기존 프로토콜 검사 35건도 다시 통과.
- 실제 브라우저 검사 56건: 브라우저와 서버 사이에 연결을 끊거나 멈추는 중계기를 두고, 순간 끊김·몇 초 끊김·조용한 끊김·새로고침·다른 탭·대기실·판 도중·관전 중·결과 화면·자리가 없어진 경우·다시 연결하는 중에 그만두기를 확인했습니다. 화면 크기 5가지(320×568, 390×844, 568×320, 932×430, 1280×800).
- 기존 브라우저 검사 다시 실행: 혼자 하기, 페어 흐름, 관전(새로고침하면 같은 자리로 돌아오는 것 포함), 닉네임, 경험치, 버전과 새 소식, 순위표.
