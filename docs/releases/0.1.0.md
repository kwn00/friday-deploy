- **칸과 단계**: 무기 6개, 패시브 6개까지 가질 수 있습니다. 칸이 다 차면 가진 것만 선택지에 나옵니다. 무기는 8단계(코드 프리즈만 4단계), 패시브는 5단계(git fork·스냅샷은 2단계)까지.
- **레벨업 선택지**: 새로 얻는 것은 설명을, 가진 것은 이번 단계에서 무엇이 좋아지는지(예: "피해 +5, 개수 +1")를 보여줍니다. 지금 칸이 몇 개 찼는지도 보여줍니다.
- **기존 강화의 변화** (모든 무기·패시브를 같은 방식으로 맞추느라 바뀌었습니다)
  - 🖨️ console.log(): 8단계까지. 2·4·6단계에 한 발씩 늘고, 3단계에 쿨다운이 줄고, 7단계에 관통.
  - 🦆 러버덕: 계속 돌지 않고, 3초 돌고 3초 쉽니다 (단계가 오르면 더 오래, 더 넓게, 더 빨리).
  - 🔣 정규표현식: 모든 적을 꿰뚫던 한 발 대신, 바라보는 방향으로 여러 발을 나란히 날립니다 (관통은 단계마다 늘어남).
  - 🤖 AI 에이전트: 한 번에 세 발을 각각 아무 버그에게 쏩니다. 단계마다 피해 +10.
  - 📋 Stack Overflow 피해 +15% → +10%, ☕ 아이스 아메리카노 이동 +8% → +10%, ⌨️ 기계식 키보드는 곱하지 않고 더해서 최대 -40%.
  - 📦 npm install: 단계마다 +40%, +30%, +20%, +20%, +25% (곱해서 최대 약 3.3배).
  - 🌙 다크 모드: 최대 체력 +20%, 고를 때 늘어난 만큼(20) 회복. 예전 설명("체력 20 회복")과 실제(40 회복)가 달랐던 것을 맞췄습니다.
  - 🖥️ 듀얼 모니터: 단계마다 +10%. 조준·비거리뿐 아니라 베기·웅덩이·폭발·오라 같은 공격의 크기도 커집니다.
- **리더보드 시즌 3**: 게임이 달라져서 새 순위표로 시작합니다.

## 난이도 (봇으로 측정)

0.0.3과 같은 시드, 20분 상한. 적이 32px 안에 오면 비켜나고 그 밖에는 경험치를 주우러 가는 봇입니다.

- 혼자 하기, "가진 것부터 키우는" 고르기: 20분을 버틴 판 8/16 (0.0.3도 8/16).
- 혼자 하기, 무작위 고르기(저주 제외): 11/16 (0.0.3은 16/16). 칸이 6개뿐이라 효과가 약한 패시브로 칸을 채우면 되돌릴 수 없어서, 아무거나 고르면 더 어렵습니다.
- 함께 하기(같은 봇 2명, 가진 것부터 키우기): 9/12 (0.0.3은 12/12).
- 조금 어려워졌지만, 판 수가 적고 작은 규칙 변화에도 판마다 결과가 크게 갈립니다 (같은 조건의 앞선 측정에서는 함께 하기 11/12). 수치는 더 맞추지 않았습니다.

## 내부 변경

- **강화를 데이터로**: 무기마다 기본 능력치(피해, 쿨다운, 개수, 크기, 속도, 지속, 관통)와 단계별 증가분을 `content.ts` 에 적고, 패시브는 그 능력치에 곱하거나 더합니다 (`stats.ts`). 선택지 문구도 이 데이터에서 만듭니다.
- **전투 코드 분리** (`combat.ts`): 무기 23종, 투사체·소환물, 바닥 영역(웅덩이·발자국·폭발 등), 같은 공격에 너무 자주 맞지 않게 하는 적별 잠금.
- **공간 격자**: 적을 틱마다 48px 칸에 넣고 충돌·조준을 주변 칸에서만 찾습니다. 틱이 이전보다 가볍습니다 (15분 판 평균 0.16~0.21ms, 0.0.3은 0.27~0.64ms, 같은 기계에서 측정).
- **전송량**: 바닥 영역은 생길 때 한 번만 남는 시간과 함께 보냅니다. 15분 한 판의 한 사람 전송량이 28~39MB 로 0.0.3(22~38MB)과 비슷합니다 (측정).
- **판정은 모두 서버**: 조준, 폭발, 얼림, 보호막, 저주, 부활, 칸 제한, 선택지 4개는 모두 서버가 정합니다. 클라이언트가 보내는 것은 지금처럼 이동 방향과 선택지 번호뿐입니다.
- 통신 규격(프로토콜) 7, 이진 스냅샷 4 (플레이어 줄에 러버덕 반경·각속도, 방화벽 반경, 보호막 / 적 줄에 얼음 / 바닥 영역 목록).
- 투사체 상한 200 → 320, 바닥 영역 상한 200.
