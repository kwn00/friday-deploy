- **새 무기 19종** (모두 23종). 레벨업 때 골라서 얻습니다.
  - ✂️ **Ctrl+X**: 바라보는 쪽을 옆으로 크게 잘라냅니다. 2단계부터 반대쪽도.
  - 🧱 **벽돌책**: 위로 던진 책이 떨어지며 여러 버그를 짓누릅니다.
  - ↩️ **롤백**: 가까운 버그 쪽으로 날아갔다가 던진 자리로 돌아오며, 오가는 동안 계속 맞힙니다.
  - 🔥 **방화벽**: 주위에 다가온 버그를 계속 태우고 살짝 밀어냅니다.
  - 💧 **핫픽스**: 버그 발밑에 웅덩이를 만들어 밟는 동안 다치게 합니다.
  - 🏓 **핑퐁**: 아무 방향으로 날아가 화면 끝에서 튕기며 오갑니다.
  - ⚡ **핫 리로드**: 주변의 아무 버그에게나 번개를 내리칩니다.
  - 🧹 **git clean -fd**: 가끔 주변을 통째로 지웁니다 (떨어진 경험치도 함께 지워짐, 보스는 피해만).
  - 🐤 **카나리아** · 🦉 **야근 부엉이**: 내 주위를 서로 반대 방향으로 돌며 폭탄을 떨어뜨립니다.
  - 📡 **브로드캐스트** · 📨 **멀티캐스트**: 네 방향(위아래 왼쪽 오른쪽 / 대각선)으로 패킷을 쏩니다.
  - 🐈 **키보드 고양이**: 제멋대로 돌아다니며 닿는 버그를 할퀴는 고양이를 풀어 둡니다.
  - 🖱️ **무한 스크롤**: 내 자리를 위아래로 길게 쓸어내립니다.
  - 👣 **커밋 히스토리**: 움직이는 동안 지나간 자리에 일정한 간격으로 커밋을 남겨 밟은 버그를 다치게 합니다.
  - 🧊 **코드 프리즈**: 시곗바늘처럼 돌아가며 광선을 쏘아 버그를 잠깐 얼립니다 (얼면 움직이지도 때리지도 못함).
  - 🔐 **2단계 인증**: 가끔 잠깐 동안 어떤 피해도 받지 않습니다.
  - 🌪️ **스프린트**: 움직이는 방향으로 벱니다. 2초 이상 달리면 2배로 세집니다.
  - 💣 **로직 폭탄**: 가까운 버그에게 던지면 닿는 곳에서 터집니다.
- **새 패시브 9종** (모두 15종): 🧪 테스트 커버리지(받는 피해 감소) · 🧘 워라밸(체력 회복) · 🚀 CDN(탄 속도) · ⏳ keep-alive(지속 시간) · 🍴 git fork(개수 +1) · 🙏 배포 기도(선택지 4개가 나올 확률) · 📚 사이드 프로젝트(경험치) · ☠️ 운영 서버 직접 수정(버그가 세지는 대신 경험치가 많음) · 📸 스냅샷(부활).
- **칸과 단계**: 무기 6개, 패시브 6개까지 가질 수 있습니다. 칸이 다 차면 가진 것만 선택지에 나옵니다. 무기는 8단계(코드 프리즈만 4단계), 패시브는 5단계(git fork·스냅샷은 2단계)까지.
- **레벨업 선택지**: 새로 얻는 것은 설명을, 가진 것은 이번 단계에서 무엇이 좋아지는지(예: "피해 +5, 개수 +1")를 보여줍니다. 지금 칸이 몇 개 찼는지도 보여줍니다.
- **기존 강화의 변화** (모든 무기·패시브를 같은 방식으로 맞추느라 바뀌었습니다)
  - 🖨️ console.log(): 8단계까지. 1단계는 0.0.3과 같고, 2·4·6단계에 한 발씩 늘고, 3단계에 쿨다운이 줄고(0.9초 → 0.8초), 7단계에 관통.
  - 🦆 러버덕: 계속 돌지 않고, 3초 돌고 3초 쉽니다 (단계가 오르면 더 오래, 더 넓게, 더 빨리).
  - 🔣 정규표현식: 모든 적을 꿰뚫던 한 발 대신, 바라보는 방향으로 여러 발을 나란히 날립니다 (관통은 단계마다 늘어남).
  - 🤖 AI 에이전트: 한 번에 세 발을 각각 아무 버그에게 쏩니다. 단계마다 피해 +10.
  - 📋 Stack Overflow 피해 +15% → +10%, ☕ 아이스 아메리카노 이동 +8% → +10%, ⌨️ 기계식 키보드는 곱하지 않고 더해서 최대 -40%.
  - 📦 npm install: 단계마다 +40%, +30%, +20%, +20%, +25% (곱해서 최대 약 3.3배).
  - 🌙 다크 모드: 최대 체력 +20%, 고를 때 늘어난 만큼(20) 회복. 예전 설명("체력 20 회복")과 실제(40 회복)가 달랐던 것을 맞췄습니다.
  - 🖥️ 듀얼 모니터: 단계마다 +10%. 조준·비거리뿐 아니라 베기·웅덩이·폭발·오라 같은 공격의 크기도 커집니다.
- **리더보드 시즌 3**: 게임이 달라져서 새 순위표로 시작합니다.

## 난이도 (봇으로 측정)

0.0.3과 같은 시드, 20분 상한. 적이 32px 안에 오면 비켜나고 그 밖에는 경험치를 주우러 가는 봇입니다.

- 혼자 하기, "가진 것부터 키우는" 고르기: 20분을 버틴 판 12/16 (0.0.3은 8/16).
- 혼자 하기, 무작위 고르기(저주 제외): 9/16 (0.0.3은 16/16). 칸이 6개뿐이라 효과가 약한 패시브로 칸을 채우면 되돌릴 수 없어서, 아무거나 고르면 더 어렵습니다.
- 함께 하기(같은 봇 2명, 가진 것부터 키우기): 11/12 (0.0.3은 12/12).
- 시작 직후는 0.0.3과 같습니다. 시작 무기 console.log() 의 1·2단계 발사 간격을 0.0.3과 같은 0.9초로 두었고, 피하지 않고 가만히 서 있는 봇이 쓰러지는 시간(가운데값 23초)과 15초까지 잡는 버그 수(13마리)가 0.0.3과 같습니다 (시드 60개).
- 판 수가 적고 작은 규칙 변화에도 판마다 결과가 크게 갈립니다 (발사 간격만 1.0초로 두고 쟀을 때는 차례로 8/16, 11/16, 9/12). 가진 것을 키우면 0.0.3과 비슷하거나 조금 쉽고, 아무거나 고르면 더 어렵습니다.

## 내부 변경

- **강화를 데이터로**: 무기마다 기본 능력치(피해, 쿨다운, 개수, 크기, 속도, 지속, 관통)와 단계별 증가분을 `content.ts` 에 적고, 패시브는 그 능력치에 곱하거나 더합니다 (`stats.ts`). 선택지 문구도 이 데이터에서 만듭니다.
- **전투 코드 분리** (`combat.ts`): 무기 23종, 투사체·소환물, 바닥 영역(웅덩이·발자국·폭발 등), 같은 공격에 너무 자주 맞지 않게 하는 적별 잠금.
- **공간 격자**: 적을 틱마다 48px 칸에 넣고 충돌·조준을 주변 칸에서만 찾습니다. 틱이 이전보다 가볍습니다 (15분 판 평균 0.16~0.21ms, 0.0.3은 0.27~0.64ms, 같은 기계에서 측정).
- **전송량**: 바닥 영역은 생길 때 한 번만 남는 시간과 함께 보냅니다. 15분 한 판의 한 사람 전송량이 28~39MB 로 0.0.3(22~38MB)과 비슷합니다 (측정).
- **판정은 모두 서버**: 조준, 폭발, 얼림, 보호막, 저주, 부활, 칸 제한, 선택지 4개는 모두 서버가 정합니다. 클라이언트가 보내는 것은 지금처럼 이동 방향과 선택지 번호뿐입니다.
- 통신 규격(프로토콜) 7, 이진 스냅샷 4 (플레이어 줄에 러버덕 반경·각속도, 방화벽 반경, 보호막 / 적 줄에 얼음 / 바닥 영역 목록).
- 투사체 상한 200 → 320, 바닥 영역 상한 200.
- 문서: README, docs/SECURITY.md.

## 확인한 것

- 타입 검사, 단위 테스트 125개, 클라이언트 빌드. 강화 테스트 18개를 새로 넣었습니다: 무기·패시브 정의와 문구 길이, 칸 제한, 피해를 주는 무기가 모두 실제로 버그를 맞히는지, 코드 프리즈·2단계 인증·git clean, 패시브 효과, 소환물, 바닥 영역을 한 번만 보내는지, 검토에서 나온 문제 4건의 재발 방지.
- 프로덕션 모드로 띄운 서버에 손으로 짠 클라이언트로 프로토콜 검사 35건, 재접속 검사 38건.
- 실제 브라우저(Playwright) 검사: 재접속 56건, 페어 흐름 20건, 관전 16건, 버전과 새 소식 54건, 닉네임·순위표·경험치 끌어당기기 등 앞선 버전의 검사 57건. 혼자 하기는 화면 크기 5가지(320×568, 390×844, 568×320, 932×430, 1280×800)에서 오류 없이 진행됩니다.

- 전송량, 틱 시간, 난이도는 위에 적은 대로 쟀습니다.
- 반박 검토 2회: 구현 전 설계 검토, 구현 후 검토(지적마다 다른 검토자가 다시 확인). 확인된 문제는 모두 고쳤습니다: 멈춘 동안 바닥 영역을 다시 보내던 것, 경험치 배율이 반올림으로 사라지던 것, 아주 작은 입력을 달리기로 치던 것, 스냅샷이 부활 상한을 올리던 것, 번쩍임 효과가 바닥 영역 상한을 차지하던 것, 롤백이 날아가는 거리보다 멀리 조준하던 것, 헷갈리는 문구.
