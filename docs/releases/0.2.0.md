# v0.2.0

## 달라진 점

- **효과음.** 공격이 맞을 때, 버그가 쓰러질 때, 경험치를 먹을 때(연달아 먹으면 음이 조금씩 올라갑니다), 내가 맞을 때 소리가 납니다.
  레벨업(PR Merged!), 강화 선택, 회복·아이템·백업·보물상자, 되살아남, 쓰러짐, 동료가 쓰러짐, 보스 등장(경보)과 처치, 30분(월요일 아침), 판 시작과 끝(Segmentation fault), 버튼에도 소리가 있습니다.
- **배경음악.** 타이틀·대기실 곡과 게임 곡이 있습니다. 크리스마스 테마에서는 타이틀에 징글벨(저작권이 끝난 곡)이 흐르고, 게임 곡이 방울 소리로 바뀝니다. 메뉴나 강화 선택창이 열려 있으면 음악이 작아지고, 판이 끝나면 멈춥니다.
- **소리 켜고 끄기.** 게임 중 메뉴에서 효과음과 음악을 따로 끌 수 있고, 타이틀 화면 왼쪽 아래 🔊 버튼으로 둘을 한꺼번에 끌 수 있습니다. 브라우저에 기억합니다.

## 내부 변경

- **소리 파일 없이 만든다.** 효과음과 음악을 모두 Web Audio 로 그 자리에서 만듭니다. 내려받는 파일이 없어 전송량이 늘지 않습니다.
- **서버는 그대로.** 언제 소리를 낼지는 화면이 이미 받는 스냅샷을 직전 것과 비교해서 정합니다 (`apps/client/src/sound-cues.ts`). 통신 규격, 서버, 게임 규칙, 리더보드 시즌은 바뀌지 않았습니다. 소리는 판정에 쓰이지 않습니다.
- **파일 나눔**
  - `sounds.ts`: 효과음(음의 목록)과 배경음악(글자 악보) 데이터. 화면을 쓰지 않아 단위 테스트로 검사합니다.
  - `sound-cues.ts`: 장면 비교 → 낼 소리. 보스 경보는 보스마다 한 번, 쓰러져 있으면 내 소리는 내지 않습니다.
  - `audio.ts`: 연주기. 같은 소리의 최소 간격과 동시에 울리는 수를 제한하고(적이 한꺼번에 쓰러져도 뭉개지지 않게), 화면을 떠나면 멈춥니다. 음악을 끄면 음을 만들지도 않습니다.
- **테마와 연결.** 테마에 `music` 이 생겨, 테마마다 곡을 바꿀 수 있습니다 (`themes.ts`).
- **브라우저 정책.** 화면을 처음 누르기 전에는 소리를 낼 수 없으므로 누르는 순간 깨웁니다. 그 전에는 오디오를 만들지 않습니다.

## 확인한 것

- 단위 테스트 통과. 새로 추가: 장면 비교로 나는 소리(쓰러짐과 시야 밖 구별, 맞음, 보스 경보 한 번, 먹은 것, 맞음·쓰러짐·되살아남·동료, 30분), 음 이름과 악보 풀기, 효과음의 길이·크기·겹침 제한, 모든 곡(테마 곡 포함)의 악보 길이와 음.
- 실제 서버를 띄우고 실제 브라우저(Chromium)로 확인: 처음 누르기 전에는 오디오가 없고 누른 뒤에 켜짐, 혼자 하기 10초 동안 만들어지는 음의 수, 효과음·음악을 끄면 새 음을 만들지 않음, 설정이 브라우저에 남음. 소리를 녹음해 크기를 쟀습니다.
- 타이틀의 소리 버튼과 메뉴를 320×568 · 390×844 · 844×390 · 1440×900 에서 확인했습니다.
