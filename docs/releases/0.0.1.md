# v0.0.1 — 첫 버전

버전 관리를 시작하는 첫 릴리즈입니다. 이전 버전이 없으므로 변경 사항은 없고, 이 시점의 게임이 가진 것을 기준으로 남깁니다.
다음 버전부터는 여기에 이전 버전과 달라진 점을 적습니다.

## 이 버전의 게임

- **혼자 하기**: 몰려오는 버그를 피해 최대한 오래 버티는 게임. 공격은 자동이고, 레벨이 오르면 강화를 하나 고릅니다 (무기 4종, 패시브 5종)
- **함께 하기**: 6자리 방 코드나 초대 링크로 최대 4명. 대기실에서 방장이 시작하고, 판이 끝나면 같은 방에서 이어서 합니다
- **관전**: 함께 하기에서 쓰러지면 시점을 움직이며 관전합니다
- **리더보드**: 혼자 / 함께 순위표. 함께 한 판은 기여도 순으로 이름을 적습니다
- 일시정지(혼자 하기), 미니맵, 회복 아이템, 피격 표시, 닉네임 표시, 경험치 끌어당기기
- 휴대폰부터 데스크톱까지 화면 크기에 맞춰 동작합니다

## 이 버전에서 추가한 것

- 타이틀 화면 구석에 버전 표기 (`v0.0.1`)
- 새 소식(릴리즈노트) 화면: 그 버전을 처음 본 브라우저에 한 번 자동으로 뜨고, 버전 표기를 누르면 다시 볼 수 있습니다
- `/healthz` 응답에 `version` 추가 (배포된 서버의 버전 확인용)
- 릴리즈 절차: 버전 브랜치(`release/x.y.z`) → PR → 승인 후 머지 → 태그와 GitHub 릴리즈 자동 생성

## 기준이 되는 값

- 통신 규격(프로토콜) 버전: 4
- 리더보드 시즌: 1
