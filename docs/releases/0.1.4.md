# v0.1.4

## 달라진 점

- **크리스마스 테마.** 메뉴와 HUD 가 크리스마스 색(짙은 소나무색 바탕, 빨강·금색)으로 바뀌고, 게임 화면에 눈이 내립니다. 바닥에 흩어진 글자에 `*` · `{*}` · `Ho` 같은 것이 섞이고, 캐릭터가 산타 모자를 씁니다. 타이틀 문구는 "크리스마스 이브 배포에서 살아남기" 입니다.
- 기기의 "동작 줄이기" 설정이 켜져 있으면 눈은 내리지 않습니다.

## 내부 변경

- **테마 구조.** 계절·행사 스킨을 한 줄로 바꿀 수 있게 했습니다.
  - `packages/shared/src/theme.ts`: 테마 이름 목록(`THEME_IDS`)과 지금 쓰는 테마(`ACTIVE_THEME`). 이 한 줄을 `'default'` 로 바꾸면 원래 화면입니다. 서버와 클라이언트가 함께 쓰는 곳에 두어, 나중에 관리자 화면에서 고르게 되면 서버가 이 값을 내려주기만 하면 됩니다 (`isThemeId` 로 받은 값을 확인).
  - `apps/client/src/themes.ts`: 테마마다 한 벌 — 화면 색(CSS 변수), 바닥 색·글자, 내리는 것(눈 등), 캐릭터 그림, 타이틀 문구. 새 테마는 기본 테마를 펼쳐 놓고 바꿀 것만 덮어씁니다.
  - `apps/client/src/apply-theme.ts`: 테마를 화면에 입힙니다 (CSS 변수, 문구, 브라우저 테마 색, 렌더러). 게임 중에 다시 불러도 됩니다.
- **CSS 색을 변수로.** `style.css` 에 직접 적혀 있던 색(버튼, 어두운 막, 반투명 바탕, 경험치 막대 등)을 모두 `:root` 의 변수로 옮겼습니다. 기본 테마 값은 그대로라 원래 화면은 달라지지 않습니다.
- 테마는 화면에만 영향을 줍니다. 서버, 통신 규격, 게임 규칙, 리더보드 시즌은 그대로입니다. 눈은 화면 크기에 비례해 최대 160개를 캔버스에 점으로 찍으므로 서버 부담과 전송량은 늘지 않습니다.

## 확인한 것

- 단위 테스트 통과. 새로 추가: 테마마다 모든 값이 있는지, 색 모양, 기본 테마가 `style.css` 의 첫 화면 색과 같은지, 캐릭터 그림의 크기(보이는 크기 = 맞는 크기)와 팔레트.
- 실제 서버를 띄우고 실제 브라우저(Chromium)로 타이틀과 혼자 하기 화면을 320×568 · 390×844 · 844×390 · 1440×900 에서 확인했습니다. 크리스마스와 기본 테마 모두.
