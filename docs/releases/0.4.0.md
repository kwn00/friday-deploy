# v0.4.0

## 달라진 점

- **시작 무기 고르기.** 타이틀의 닉네임 아래에서 시작 무기를 고릅니다: 🖨️ `console.log()` (기본) · ↩️ 롤백 · 🤖 AI 에이전트 · 🔥 방화벽. 고른 무기 1단계로 시작하고 무기 칸 하나를 씁니다.
  - 브라우저가 고른 무기를 기억합니다. 함께 하기 대기실에서도 판이 시작되기 전까지 바꿀 수 있고, 사람 목록에 각자의 무기 아이콘이 보입니다.
  - 순위표에 이름 앞에 각자의 시작 무기 아이콘이 나옵니다 (0.4.0 의 기록부터. 예전 기록은 아이콘 없이 그대로 보입니다).
  - 방화벽 말고는 진화 길이 있습니다: `console.log()` → 🐞 디버거, 롤백 → ⏪ git reset --hard, AI 에이전트 → 🧠 AGI.
- **합치기 두 개의 모양이 바뀌었습니다.** 재료와 똑같은 공격이 나가던 것을 새 모양으로 바꿨습니다.
  - 🌊 **패킷 플러딩**: 1.2초마다 내 자리에서 패킷 물결이 반경 234 까지 퍼집니다. 물결이 지나가는 버그를 모든 방향으로, 관통 제한 없이 한 번씩 맞히고 밀어냅니다. 따라오는 옅은 물결 수가 겹 수이고 (기본 3겹, git fork 로 늘어남) 겹마다 피해 10 입니다.
  - 🕐 **24시간 모니터링**: 카나리아와 부엉이 두 마리 대신 아주 센 감시 새 한 마리가 내 둘레(56)를 쉬지 않고 돌며, 0.25초마다 큰 폭탄(반경 72, 피해 240)을 떨굽니다. 몸에 붙은 버그도 맞힙니다.
- **새 진화 셋.** 최대 단계 무기와 짝 패시브를 함께 가지고 보물상자를 열면 진화합니다.

  | 무기 (최대 단계) | + 패시브 | → 진화 | 바뀌는 것 |
  | --- | --- | --- | --- |
  | ↩️ 롤백 | 🙏 배포 기도 | ⏪ git reset --hard | 부메랑 넷을 부채꼴로 던집니다. 피해 45, 관통 제한 없음, 가끔(25%, 운이 곱해짐) 두 배로 벱니다 |
  | 🔣 정규표현식 | 🚀 CDN | 🔎 grep -r | 가장 가까운 버그 쪽으로 0.4초마다 네 줄을 쏟아냅니다. 피해 18, 셋까지 꿰뚫습니다 |
  | 🤖 AI 에이전트 | 📚 사이드 프로젝트 | 🧠 AGI | 크고 느린 답 셋을 쏩니다. 피해 150, 넷까지 꿰뚫습니다 |

- **레벨업 새로고침이 한 판에 세 번입니다** (예전 두 번). 🙏 배포 기도를 고를 때마다 한 번씩 더 생겨서, 최대 여덟 번입니다. 함께 하기에서도 사람마다 따로 셉니다.
- **밸런스.** 깎은 것은 없습니다. 무기를 세게 하지 못하는 아이템과 약한 무기를 올렸습니다. 무기·패시브 수치는 이제 뱀파이어 서바이버즈 위키 값이 아니라 우리 밸런스로 고칩니다 (최대 단계는 그대로).
  - **생존·편의 패시브 7종이 피해량도 올립니다**: ☕ 아이스 아메리카노 · 📦 npm install · 🌙 다크 모드 · 🧪 테스트 커버리지 · 🧘 워라밸 · 📚 사이드 프로젝트 · 🙏 배포 기도. 1단계에 피해 +5%, 그 뒤 단계마다 +1% (하나에 최대 +9%). 레벨업 선택지와 메뉴에 "피해량" 줄로 나옵니다.
  - 🧘 워라밸: 1초에 체력 +0.2 → +0.5 (단계마다). 피자를 더 잘 듣게 하는 효과는 예전 크기 그대로입니다.
  - 📚 사이드 프로젝트: 얻는 경험치 +8% → +15% (단계마다).
  - 🌙 다크 모드: 고르면 늘어난 최대 체력만큼 바로 찹니다 (보물상자로 올라도 같습니다).
  - ☠️ 운영 서버 직접 수정: 한 번만 고릅니다. 가진 뒤에는 레벨업 선택지와 보물상자에 나오지 않습니다.
  - 🚀 CDN: 스스로 겨누는 무기(`console.log()`·디버거·AI 에이전트·멀티스레드·정규표현식·grep -r)가 속도 배율만큼 더 멀리서 겨눕니다. 화면 밖은 겨누지 않습니다.
  - 🔐 2단계 인증: 방패가 다시 차는 시간 10 → 8초. 방패가 한 대를 막으면 둘레(48)의 버그를 때리고(피해 10) 밀쳐 냅니다.

## 고친 것

- **롤백이 부메랑처럼 돌아옵니다.** 0.1.2 부터 롤백이 처음부터 두 배 빠르게, 지속시간이 다 지나서야 되돌아서서, 화면 밖(1단계 약 525px)까지 날아갔다가 던진 자리로 돌아오지 못했습니다. 투사체의 나이를 "남은 시간"으로 세었는데 롤백은 남은 시간을 기준 시간의 1.5배로 주기 때문이었습니다. 이제 속도×지속/4 (1단계 135px) 만큼 날아가 되돌아오고, 던진 자리를 지나 뒤로 날아가며 같은 버그를 오가며 두 번 벱니다. git reset --hard 도 같습니다.
- **무한 스크롤 3·7단계가 오히려 약해지던 것.** 단계가 오르면 남는 시간과 함께 쿨다운이 길어져, 그 단계에서 피해가 줄었습니다. 같은 버그를 다시 맞히는 간격을 줄여 모든 단계가 이전 단계 이상이 되게 했습니다.
- **빠른 투사체가 작은 버그를 건너뛰던 것** (멀티스레드, 브로드캐스트·멀티캐스트 7단계): 한 틱에 움직이는 거리가 작은 버그보다 커서 맞지 않고 지나갔습니다.

## 내부 변경

- **통신**: 통신 규격 버전 13 → 14, 이진 스냅샷 버전 8 → 9. 예전 화면은 처음 연결할 때 새로고침하라는 안내를 받습니다.
  - 종류 번호는 모두 맨 뒤에 붙였습니다: 무기 `git_reset`·`grep_r`·`agi` (`WEAPON_IDS`, 32개), 투사체 `watch`, 바닥 영역 `wave`.
  - `hello` 에 시작 무기 **번호**(`starter`, 없으면 0번), 대기실 메시지 `{ t: 'starter', choice }`, roster 에 각자의 `start` 를 더했습니다.
  - 내 강화 단계(`me.up`)를 모든 강화의 단계 목록 대신 "가진 개수 + (번호, 단계) 쌍"으로 보냅니다. 강화가 늘어도 스냅샷이 커지지 않고, 혼자 하기 첫 60초의 스냅샷이 평균 196B(0.3.5) → 152B 로 줄었습니다.
  - 인증 전 메시지는 버전부터 봅니다 (`greetingVersion`): 다음 버전 화면이 이 서버에 없는 시작 무기 번호를 보내도 위반이 아니라 `version_mismatch` 안내를 받습니다.
- **서버가 정한다**: 시작 무기는 서버의 허용 목록(`STARTER_WEAPONS`)의 번호로만 고르고, 무엇으로 몇 단계로 시작하는지는 서버가 정합니다. 바꾸기는 판이 시작되기 전에만 받고, 대기실을 붙잡는 활동으로 세지 않습니다. 새로고침 횟수, 저주를 선택지에서 빼기, 피해량 보너스, 다크 모드 회복, 반격도 모두 서버의 시뮬레이션이 정합니다. `docs/SECURITY.md` 의 표에 반영했습니다.
- **시뮬레이션**
  - 패킷 플러딩의 물결은 서버가 고리 하나로 판정합니다: 이번 틱에 지나간 띠 안의 버그만, 영역마다 이미 맞힌 버그를 기억해 한 번씩 (`Zone` 의 서버 전용 `hit`·`band`. 스냅샷에는 싣지 않습니다).
  - 감시 새는 진화하는 순간 카나리아의 id 와 각도를 이어받아 끊기지 않고 보이고, 레벨업을 고르는 동안에도 보입니다.
  - 롤백 움직임: 투사체에 쏜 뒤 지난 시간(`Shot.age`)을 두고 그것으로 계산합니다.
  - 커밋 히스토리 발자국은 한 사람에 30개까지입니다 (함께 하기에서 네 명이 모두 가지면 피해 영역 상한 200 에 닿아 다른 무기의 영역이 생기지 않던 것). 영역 수를 셀 때 이번 틱에 끝난 영역은 세지 않습니다.
- **리더보드·통계 저장**: 기록 표에 `member_starts text[]`, 통계 표(`upgrade_stats_by_version`)에 `started bigint NOT NULL DEFAULT 0` 열을 더했습니다 (예전 열 추가와 같은 방식). 예전 기록과 통계는 그대로 읽힙니다. 저장된 시작 무기는 지금의 후보가 아니라 "진화하지 않은 무기"인지로 확인해서, 나중에 후보가 바뀌어도 아이콘이 사라지지 않습니다.
- **공개 API**: `/api/leaderboard` 의 기록에 `startsBy` (이름과 같은 순서의 시작 무기 id), `/api/stats/upgrades` 의 아이템에 `started` (시작 무기로 고른 판 수. `offered`·`picked` 에 섞지 않습니다).
- **화면**: 시작 무기 타일(네이티브 라디오, 방향키로 고름), 물결·감시 새·청록 폭발·넓어진 광선 그림, 타이틀·대기실 배치(시작 무기 줄이 들어가도 휴대폰과 노트북의 실제 브라우저 높이에서 한 화면에 들어가게).
- **테스트**: 방 테스트가 가끔 실패하던 것을 고쳤습니다 (서버 난수로 고른 카드가 배포 기도·git clean 일 때 결과가 달라짐).
- 처음 화면을 받을 때 gzip 기준 약 3.4kB 늘었습니다 (JS 49.66 → 51.93kB, CSS 5.34 → 6.00kB, HTML 3.28 → 3.73kB).
- 문서: README (시작 무기, 진화 표, 수치 원칙, 새로고침, API), docs/SECURITY.md (메시지 표, 위협 표).
- 리더보드 시즌은 그대로(시즌 0)입니다. 지운 기록은 없습니다.

- 봇으로 밸런스를 쟀습니다 (서버 없이 시뮬레이션, 0.3.5 와 나란히).

  - 진화 무기는 22분에 재료 최대 단계의 1.5~8배입니다 (24시간 모니터링의 둘러싸였을 때만 1.3배. 칸 하나가 비는 합치기입니다). 새 패킷 플러딩·24시간 모니터링은 22분에 0.3.5 의 같은 무기보다 셉니다.
